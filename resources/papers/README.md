# Статьи и аналитические материалы

| Материал | Аннотация | Связанные темы |
|---|---|---|
| [Hidden Technical Debt in Machine Learning Systems](https://papers.nips.cc/paper/5656-hidden-technical-debt-in-machine-learning-systems) | Классическая работа о скрытых зависимостях и техническом долге ML-систем. | Жизненный цикл, архитектура, сопровождение |
| [The ML Test Score](https://research.google/pubs/the-ml-test-score-a-rubric-for-ml-production-readiness-and-technical-debt-reduction/) | Рубрика зрелости проверок и готовности ML-системы к эксплуатации. | Тестирование, quality gate |
| [Rules of Machine Learning](https://developers.google.com/machine-learning/guides/rules-of-ml) | Практические правила построения и развития производственных ML-систем. | Проектирование, мониторинг, итерации |
| [Model Cards for Model Reporting](https://arxiv.org/abs/1810.03993) | Подход к документированию назначения, ограничений и результатов моделей. | Артефакты, риски, прозрачность |

Дата проверки ссылок: 2026-07-20. При использовании студент указывает конкретный тезис и объясняет его связь с собственным проектом.
