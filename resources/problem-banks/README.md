# Банк задач и инцидентов

## Базовые сценарии

- нарушение схемы и типов входных данных;
- drift признаков без подтверждённого ухудшения качества;
- снижение F1 без выраженного одномерного drift;
- неуспешный выпуск и readiness failure;
- рост HTTP 4xx из-за некорректных клиентов;
- рост HTTP 5xx из-за ошибки сервиса;
- рост p95 latency;
- рассинхронизация версии модели и сервиса;
- утечка секрета в конфигурацию;
- отсутствие прослеживаемости данных и модели.

Рабочие сценарии и ожидаемые сигналы: [monitoring/incident-scenarios.md](../starter-project/project-baseline/monitoring/incident-scenarios.md).

При выдаче преподаватель меняет хотя бы один параметр, имя файла, порог либо причину, чтобы задание не сводилось к механическому повторению эталона.
