# Образовательные ресурсы

## Доступно в комплекте

- [каркас учебного ML-проекта](starter-project/README.md);
- воспроизводимый генератор учебных данных и контракт;
- версии данных для DVC, drift и трёх типов инцидентов;
- шаблоны конфигураций, политики выпуска и постмортема;
- описание учебных сценариев инцидентов и ожидаемых сигналов;
- девять коротких тестов без ключа;
- шаблоны отчётов, архитектурных материалов и запросов к LLM;
- аннотированные статьи, книги и справочные ресурсы.

Готовые реализации тестов, CI, DVC-пайплайна, MLflow-экспериментов, API, контейнеризации, менеджера выпуска, мониторинга и диагностических скриптов в комплект не входят: они выстраиваются в ходе лабораторных работ.

## Основные каталоги

- [`datasets/`](datasets/README.md) — источник и описание учебных данных;
- [`starter-project/project-baseline/`](starter-project/project-baseline/README.md) — каркас учебного проекта;
- [`templates/`](templates/README.md) — шаблоны отчётов;
- [`problem-banks/`](problem-banks/README.md) — сценарии и компенсирующие задания;
- [`test-banks/`](test-banks/README.md) — тестовые материалы ФОС;
- [`llm-prompts/`](llm-prompts/README.md) — правила и шаблоны работы с генеративным ИИ;
- [`benchmarks/`](benchmarks/README.md) — внутренние контрольные ориентиры;
- [`papers/`](papers/README.md), [`textbooks/`](textbooks/README.md), [`other/`](other/README.md) — аннотированные источники.
