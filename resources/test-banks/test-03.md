# Тест 3. CI/CD для ML-проектов

**Назначение:** короткий текущий контроль после соответствующей лекции.

**Формат:** 4 вопроса с выбором одного ответа. Рекомендуемое время — 5–7 минут. Максимум за тест — 1 балл.

**Допустимые ресурсы:** без обращения к готовому ключу; преподаватель определяет, разрешены ли конспект и официальная документация. Использование генеративного ИИ во время теста не допускается, если преподаватель прямо не установил иной режим.

## 1. Что означает CI?

- А) Автоматическая интеграция изменений с запуском проверок
- Б) Ручное обучение модели раз в год
- В) Только мониторинг сервера
- Г) Хранение датасета в архиве

## 2. Что является артефактом сборки?

- А) Собранный пакет, контейнер или отчёт тестов
- Б) Случайная строка в коде
- В) Пароль пользователя
- Г) Описание вакансии

## 3. Как следует работать с секретами в CI?

- А) Хранить в защищённом хранилище переменных
- Б) Коммитить в открытый репозиторий
- В) Писать в README
- Г) Передавать в имени ветки

## 4. Что такое quality gate?

- А) Критерий допуска изменения по результатам проверок
- Б) Графический редактор
- В) Формат датасета
- Г) Команда удаления контейнера

## Оценивание

- 4 правильных ответа — 1 балл;
- 3 правильных ответа — 0,75 балла;
- 2 правильных ответа — 0,5 балла;
- 0–1 правильный ответ — 0 баллов.

При переносе в LMS допускается округление в соответствии с настройками курса при сохранении общего максимума 1 балл.
