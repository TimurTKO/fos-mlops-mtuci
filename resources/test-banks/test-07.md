# Тест 7. Стратегии развёртывания и оркестрация

**Назначение:** короткий текущий контроль после соответствующей лекции.

**Формат:** 4 вопроса с выбором одного ответа. Рекомендуемое время — 5–7 минут. Максимум за тест — 1 балл.

**Допустимые ресурсы:** без обращения к готовому ключу; преподаватель определяет, разрешены ли конспект и официальная документация. Использование генеративного ИИ во время теста не допускается, если преподаватель прямо не установил иной режим.

## 1. Что предполагает blue-green deployment?

- А) Два окружения с переключением трафика
- Б) Обучение двух моделей без сервиса
- В) Удаление старой версии до тестов
- Г) Только ручной запуск

## 2. Что такое canary release?

- А) Постепенное направление части трафика на новую версию
- Б) Полная остановка сервиса
- В) Сжатие датасета
- Г) Копирование README

## 3. Когда следует выполнять откат?

- А) При нарушении критериев качества или доступности
- Б) После каждого успешного теста
- В) Только в конце семестра
- Г) Никогда

## 4. Какая сущность Kubernetes поддерживает желаемое число экземпляров приложения?

- А) Deployment
- Б) README
- В) DataFrame
- Г) Notebook

## Оценивание

- 4 правильных ответа — 1 балл;
- 3 правильных ответа — 0,75 балла;
- 2 правильных ответа — 0,5 балла;
- 0–1 правильный ответ — 0 баллов.

При переносе в LMS допускается округление в соответствии с настройками курса при сохранении общего максимума 1 балл.
