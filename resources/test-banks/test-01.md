# Тест 1. Жизненный цикл ML-системы и роли

Назначение: короткий текущий контроль после соответствующей лекции.

Формат: 4 вопроса с выбором одного ответа. Рекомендуемое время — 5–7 минут. Максимум за тест — 1 балл.

Допустимые ресурсы: без обращения к готовому ключу; преподаватель определяет, разрешены ли конспект и официальная документация. Использование генеративного ИИ во время теста не допускается, если преподаватель прямо не установил иной режим.

## 1. Какой результат наиболее точно соответствует задаче MLOps?

- А) Только обученная модель в ноутбуке
- Б) Воспроизводимый и сопровождаемый ML-сервис
- В) Набор презентаций о модели
- Г) Только очищенный датасет

## 2. Что относится к техническому долгу ML-системы?

- А) Зафиксированные версии зависимостей
- Б) Автоматические тесты
- В) Неявные зависимости и ручные шаги запуска
- Г) Документированный API

## 3. Что обеспечивает воспроизводимость эксперимента?

- А) Только сохранённая метрика
- Б) Запуск на любом случайном датасете
- В) Отсутствие логирования
- Г) Связь версий кода, данных, конфигурации и модели

## 4. Какая роль в большей степени отвечает за эксплуатационный контур модели?

- А) MLOps-инженер
- Б) Только аналитик данных
- В) Дизайнер интерфейсов
- Г) Технический писатель

## Оценивание

- 4 правильных ответа — 1 балл;
- 3 правильных ответа — 0,75 балла;
- 2 правильных ответа — 0,5 балла;
- 0–1 правильный ответ — 0 баллов.

При переносе в LMS допускается округление в соответствии с настройками курса при сохранении общего максимума 1 балл.
