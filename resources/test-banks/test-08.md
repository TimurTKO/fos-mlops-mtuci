# Тест 8. Технический и ML-мониторинг

**Назначение:** короткий текущий контроль после соответствующей лекции.

**Формат:** 4 вопроса с выбором одного ответа. Рекомендуемое время — 5–7 минут. Максимум за тест — 1 балл.

**Допустимые ресурсы:** без обращения к готовому ключу; преподаватель определяет, разрешены ли конспект и официальная документация. Использование генеративного ИИ во время теста не допускается, если преподаватель прямо не установил иной режим.

## 1. Что характеризует latency?

- А) Время ответа сервиса
- Б) Размер датасета
- В) Число веток Git
- Г) Количество признаков

## 2. Чем data drift отличается от concept drift?

- А) Data drift — изменение входных данных; concept drift — изменение связи входов и цели
- Б) Они полностью одинаковы
- В) Concept drift относится только к сети
- Г) Data drift означает удаление модели

## 3. Для чего применяются Prometheus и Grafana?

- А) Сбор метрик и визуализация мониторинга
- Б) Разметка данных
- В) Хранение исходного кода
- Г) Сборка Docker-образа

## 4. Что может быть основанием для переобучения?

- А) Устойчивое ухудшение качества на актуальных данных
- Б) Смена имени репозитория
- В) Успешный health-check
- Г) Добавление комментария

## Оценивание

- 4 правильных ответа — 1 балл;
- 3 правильных ответа — 0,75 балла;
- 2 правильных ответа — 0,5 балла;
- 0–1 правильный ответ — 0 баллов.

При переносе в LMS допускается округление в соответствии с настройками курса при сохранении общего максимума 1 балл.
