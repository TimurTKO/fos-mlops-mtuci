# Контрольные ориентиры и базовые линии

В курсе не используется единый публичный leaderboard: оценивается инженерная воспроизводимость, а не достижение максимальной метрики на конкретном датасете.

## Внутренние ориентиры

| Ориентир | Назначение | Проверка |
|---|---|---|
| F1 базовой модели не ниже 0,70 | минимальная работоспособность учебной модели | `pytest` и отчёт обучения |
| Автоматические тесты собственного проекта | регрессия кода, данных, модели, API и конфигураций | `pytest` |
| Воспроизводимый DVC-пайплайн | связь данных, параметров и модели | `dvc repro`, `dvc checkout` |
| Не менее 3 сопоставимых MLflow run | обоснование выбора модели | таблица сравнения и registry |
| Health/readiness/smoke | допуск версии к эксплуатации | автоматическая проверка релиза |
| Нормальный и drift-сценарий | различение изменения данных и качества | drift-отчёт и инженерное заключение |

Порог конкретной модели может быть изменён преподавателем до начала работы. Сравнивать следует только запуски на одной версии тестовой выборки и с одинаковой процедурой расчёта.
