# Шаблон запроса на разбор технической ошибки

```text
Контекст проекта:
- назначение компонента:
- версии Python и библиотек:
- команда запуска:
- ожидаемый результат:
- фактический результат и полный текст ошибки:

Ограничения:
- не предлагай отключать проверки безопасности;
- не используй секреты, токены и персональные данные;
- предложи сначала минимальную диагностическую проверку;
- отдели подтверждённые факты от гипотез;
- для каждого исправления укажи способ проверки и отката.
```

После ответа студент фиксирует, какие рекомендации были применены, какие отклонены и какими тестами проверен результат.
