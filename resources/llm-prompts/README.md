# LLM-сервисы и промпты

Генеративный ИИ является вспомогательным ресурсом, а не источником готового решения для защиты.

| Материал | Аннотация | Связанные КИМ | Доступ | Условия | Дата проверки |
|---|---|---|---|---|---|
| [Шаблон запроса на разбор ошибки](debugging-prompt-template.md) | Помогает сформулировать контекст, ограничения и способ проверки ответа | ЛР1–ЛР9 | локальный файл | не передавать секреты, ПДн и закрытый код | 2026-07-20 |
| [Декларация использования ИИ](../../Project/ai-use-declaration-template.md) | Фиксирует инструмент, задачу, результат и верификацию | Проект и все ЛР | локальный файл | обязательна при использовании ИИ | 2026-07-20 |

При добавлении нового промпта указываются модель/сервис, назначение, входные данные, ожидаемый формат, ограничения, риски утечки и способ независимой проверки результата.
