# Учебные сценарии инцидентов

| Файл / режим | Что изменено | Ожидаемый сигнал | Основной учебный вывод |
|---|---|---|---|
| `incident_bad_schema.csv` | Удалён признак, добавлены пропуски и строковые значения | Проверка контракта завершается ошибкой | Некорректные данные должны быть остановлены до инференса |
| `production_drift.csv` | Сдвинуты распределения трёх признаков | PSI выявляет drift; F1 может оставаться приемлемым | Drift не равен автоматической необходимости переобучения |
| `incident_degraded.csv` | Нарушена совместная структура признаков при сохранении маргинальных распределений | F1 снижается, PSI может не сработать | Одномерный drift-мониторинг не обнаруживает все виды деградации |
| `SIMULATE_STARTUP_FAILURE=1` | Кандидат падает при старте | readiness и smoke-проверка не проходят | Выпуск должен автоматически останавливаться или откатываться |
| `--invalid-every N` | Часть API-запросов имеет неверную длину признаков | Растёт доля 4xx | Ошибки клиентов и ошибки сервиса следует различать |
