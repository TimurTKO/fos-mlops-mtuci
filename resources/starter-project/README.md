# Стартовый ML-проект

Основной рабочий ресурс: [`project-baseline/`](project-baseline/README.md).

В студенческом комплекте он содержит:

- исходный Jupyter Notebook с прототипом модели `LogisticRegression`;
- воспроизводимый генератор синтетических данных и контракт данных;
- структуру каталогов `src/tests/configs` и публичные интерфейсы модулей;
- шаблоны конфигураций: параметры, окружение, зависимости;
- шаблоны `dvc.yaml`, `Dockerfile`, `compose.yaml`, CI и конфигураций Prometheus;
- шаблоны политики выпуска и постмортема;
- описание учебных сценариев инцидентов.

Реализация модулей, тестов, пайплайна, API, контейнеризации, мониторинга и диагностики выполняется последовательно в ходе лабораторных работ. Места, требующие реализации, помечены комментариями `TODO` со ссылкой на соответствующую работу.

Имена модулей, функций и их параметры менять не требуется: на них опираются задания и критерии оценивания.
