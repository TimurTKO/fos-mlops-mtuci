# Стартовый ML-проект

Основной рабочий ресурс: [`project-baseline/`](project-baseline/README.md).

Он содержит:

- исходный Jupyter Notebook и структурированный Python-проект;
- воспроизводимый генератор синтетических данных;
- модель `LogisticRegression`;
- FastAPI и автоматические тесты;
- CI, DVC и MLflow;
- Dockerfile, Docker Compose, smoke-тест и обновление/откат;
- Prometheus/Grafana, дашборд и alert rules;
- drift-анализ, генератор трафика и расследование инцидентов.

Проект используется как техническая база для последовательного выполнения лабораторных работ. Для студенческой выдачи преподаватель создаёт облегчённую ветку с удалёнными решениями и оставленными `TODO`.
