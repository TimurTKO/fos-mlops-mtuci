# Учебный датасет

## Назначение

Датасет используется как единый ресурс сквозного проекта по дисциплине. Он не содержит персональных, медицинских, финансовых или иных реальных данных. Набор генерируется локально и воспроизводимо с помощью `scikit-learn`.

## Быстрый запуск

```bash
python generate_data.py
```

По умолчанию файлы создаются в каталоге `generated/`. Для другого каталога:

```bash
python generate_data.py --output-dir ./my-data --random-state 42
```

## Состав

| Файл | Назначение |
|---|---|
| `train.csv` | Обучение базовой модели |
| `test.csv` | Оценка качества и регрессионные тесты |
| `production_normal.csv` | Нормальный поток новых данных |
| `updated.csv` | Новая версия данных для лабораторной по DVC |
| `production_drift.csv` | Контролируемый сдвиг распределения признаков |
| `incident_degraded.csv` | Сценарий деградации качества модели |
| `incident_bad_schema.csv` | Нарушение контракта данных: пропущенный столбец, пропуски и неверный тип |
| `metadata.json` | Параметры генерации, контрольные суммы и описание версий |

## Контракт данных

Контракт приведён в [`data_contract.json`](data_contract.json). Основной вариант содержит 12 числовых признаков `feature_00`–`feature_11` и бинарную целевую переменную `target`.

## Связь с лабораторными работами

- ЛР1: исходный прототип и воспроизводимый запуск;
- ЛР2: проверки схемы, типов, пропусков и качества данных;
- ЛР3: запуск проверок в CI;
- ЛР4: версии `train.csv` и `updated.csv` в DVC;
- ЛР5: сравнение экспериментов;
- ЛР8: сравнение `production_normal.csv` и `production_drift.csv`;
- ЛР9: диагностика `incident_degraded.csv` или `incident_bad_schema.csv`.

## Лицензия и условия использования

Код генератора распространяется вместе с репозиторием по его лицензии. Сгенерированные данные являются синтетическими и предназначены для образовательного использования.
