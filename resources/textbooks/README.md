# Учебники и книги

| Издание | Назначение | Связанные модули |
|---|---|---|
| Chip Huyen. *Designing Machine Learning Systems* | Проектирование жизненного цикла, данные, развёртывание и мониторинг. | М1–М4 |
| Cathy Chen et al. *Reliable Machine Learning* | Надёжность, тестирование, выпуск и эксплуатация моделей. | М1, М3, М4 |
| Emmanuel Ameisen. *Building Machine Learning Powered Applications* | Переход от постановки задачи к работающему ML-приложению. | М1–М3 |
| Noah Gift, Alfredo Deza. *Practical MLOps* | Практики CI/CD, контейнеризации и облачной эксплуатации. | М1–М4 |

Конкретное издание и доступ определяются библиотекой образовательной организации. Книга не заменяет официальную документацию используемой версии инструмента.
