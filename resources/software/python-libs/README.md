# Python-библиотеки учебного проекта

## Базовый контур

| Библиотека | Назначение |
|---|---|
| `pandas` | загрузка и проверка табличных данных |
| `numpy` | числовые операции и генерация сценариев |
| `scikit-learn` | модель, метрики и синтетический датасет |
| `joblib` | сохранение базового артефакта модели |
| `pytest` | автоматические проверки |
| `FastAPI`, `Pydantic`, `Uvicorn` | API инференса |

## Модуль 2

| Библиотека | Назначение |
|---|---|
| `DVC` | граф пайплайна, cache, версии данных и моделей |
| `MLflow` | трекинг экспериментов, артефакты и Model Registry |
| `PyYAML` | чтение и проверка конфигураций YAML |

Актуальные диапазоны версий приведены в [`pyproject.toml`](../../starter-project/project-baseline/pyproject.toml) и [`requirements-mlops.txt`](../../starter-project/project-baseline/requirements-mlops.txt). В учебном проекте используются диапазоны совместимых мажорных версий, а конкретное окружение фиксируется студентом в lock-файле выбранного менеджера зависимостей или в отчёте окружения.
