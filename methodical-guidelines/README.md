# Методические указания

- [Для обучающихся](students/README.md)

Методические указания преподавателям по оцениванию и по использованию ресурсов в студенческий комплект не входят. Критерии оценивания при этом открыты: они приведены в рубриках модулей и в [`Exam/README.md`](../Exam/README.md).

Приведённые ниже разделы описывают организацию занятий и полезны обучающимся для понимания условий проведения работ.

## Проведение модуля 3

Перед ЛР №6 преподаватель проверяет доступность Docker и выдаёт альтернативу для устройств без локальной виртуализации: учебная VM либо парная демонстрация при обязательной индивидуальной защите. Перед ЛР №7 сохраняется стабильный тег образа; искусственный отказ не должен затрагивать внешние сервисы. Журнал релиза не содержит секретов.

## Проведение модуля 4

Перед ЛР №8 преподаватель проверяет порты 8000, 9090 и 3000 и заранее загружает образы Prometheus/Grafana либо предоставляет VM. Студентам разъясняется, что PSI — только один из индикаторов и не доказывает concept drift. Для ЛР №9 сценарии распределяются индивидуально; исходные доказательства сохраняются, а разрушительные действия выполняются только в локальном учебном окружении.

При оценивании важно проверять не красоту дашборда, а корректность выбранных сигналов, воспроизводимость сценария и обоснованность реакции.
