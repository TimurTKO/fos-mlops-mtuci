# Внесение изменений

1. Создайте отдельную ветку.
2. Вносите одно логически завершённое изменение на коммит.
3. Проверяйте относительные ссылки.
4. Не добавляйте секреты, персональные данные студентов и крупные бинарные артефакты.
5. Перед слиянием запустите проверки своего проекта: `pytest` и обязательные команды воспроизводимости из README.
6. Перед публикацией комплекта запустите `python tools/check_student_delivery.py`.
