# Модуль 4. Эксплуатация, мониторинг и инциденты

## Результат модуля

Обучающийся разворачивает контур наблюдаемости ML-сервиса, получает технические и модельные сигналы, воспроизводимо моделирует изменения входных данных, диагностирует интеграционный инцидент и обосновывает решение: наблюдение, исправление, переобучение либо откат.

## Технические ресурсы

- инструментирование FastAPI и endpoint `/metrics`;
- Prometheus 3.11.2 и правила контроля;
- Grafana 13.0.3 с автоматически подготовленным источником данных и учебным дашбордом;
- скрипт генерации нормального и аномального трафика;
- анализатор PSI и качества модели;
- диагностический сценарий для трёх типов инцидентов;
- шаблон постмортема.

Все сценарии запускаются на CPU и не требуют внешних облачных сервисов.
