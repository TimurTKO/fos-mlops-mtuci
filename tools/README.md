# Инструменты проверки

`check_student_delivery.py` проверяет состав студенческого комплекта по манифесту [`.student-exclude`](../.student-exclude): отсутствие ключей ответов, эталонных решений и преподавательских материалов, наличие обязательных учебных материалов и наличие маркера `TODO` в файлах-каркасах. Проверка использует конкретные пути, известные имена файлов и точные структурные сигнатуры, поэтому обычные слова методических текстов не вызывают ложных срабатываний.

## Запуск

Из корня комплекта:

```bash
python tools/check_student_delivery.py
```

Ненулевой код возврата означает, что состав комплекта не соответствует манифесту.

## Проверка учебного проекта

Технические проверки собственного проекта выполняются его собственными средствами по мере выполнения лабораторных работ:

```bash
python resources/starter-project/project-baseline/scripts/generate_data.py --output-dir data
pytest
```

Эталонный валидатор полной экспертно-преподавательской версии репозитория в студенческий комплект не входит.

Скрипты не запускают Docker. Контейнерная сборка, Prometheus и Grafana проверяются отдельно на машине с Docker Engine/Desktop.
