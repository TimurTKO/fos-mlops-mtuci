## Наблюдаемые результаты

1. Пайплайн полностью восстанавливается командой `dvc repro`.
2. Изменение параметров или исходного кода запускает только зависимые этапы.
3. Версии данных, параметров, модели и метрик однозначно связаны с Git-коммитом и `dvc.lock`.
4. Эксперименты содержат параметры, метрики, артефакты и сведения о версии данных.
5. Выбор модели основан на заранее определённом критерии, а не на случайном просмотре результатов.
6. Выбранная модель зарегистрирована и снабжена понятным статусом или алиасом.
