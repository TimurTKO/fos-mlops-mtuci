# Чек-лист сдачи сквозного проекта

Чек-лист заполняется студентом перед фиксацией версии, представляемой на зачёт.

## 1. Идентификация версии

- [ ] Указаны URL репозитория и защищаемый Git SHA/тег.
- [ ] Рабочее дерево чистое, незакоммиченные изменения отсутствуют.
- [ ] README соответствует защищаемой версии.
- [ ] В репозитории отсутствуют секреты, токены, пароли и персональные данные.

## 2. Воспроизводимость

- [ ] Описана установка зависимостей в чистом окружении.
- [ ] Зафиксированы версии Python и основных инструментов.
- [ ] Данные формируются или восстанавливаются документированной командой.
- [ ] Обучение модели воспроизводится с фиксированной конфигурацией.
- [ ] Артефакт модели однозначно связан с кодом и данными.

## 3. Тестирование и CI

- [ ] Локально проходят тесты кода.
- [ ] Проходят проверки контракта и качества данных.
- [ ] Проходят проверки загрузки и предсказания модели.
- [ ] Проходят тесты `/health`, `/ready` и `/predict`.
- [ ] CI запускается при изменении кода и блокирует нарушение quality gate.

## 4. DVC и MLflow

- [ ] `dvc repro` воспроизводит обязательные этапы.
- [ ] `dvc.lock` соответствует защищаемой версии.
- [ ] Проведено не менее трёх сопоставимых экспериментов.
- [ ] Зафиксированы параметры, метрики, артефакты, Git SHA и версия данных.
- [ ] Выбор модели обоснован заранее объявленным quality gate.

## 5. API и развёртывание

- [ ] API валидирует корректные и некорректные запросы.
- [ ] Docker-образ собирается без секретов.
- [ ] Compose запускает необходимые компоненты.
- [ ] Readiness и smoke-проверка подтверждают готовность сервиса.
- [ ] Подготовлен воспроизводимый сценарий обновления и отката.

## 6. Мониторинг и инцидент

- [ ] Prometheus получает метрики API.
- [ ] Grafana отображает релевантные показатели.
- [ ] Сформирована штатная базовая линия.
- [ ] Сценарий drift/quality degradation воспроизводится.
- [ ] Постмортем содержит хронологию, влияние, корневую причину, восстановление и профилактику.
- [ ] После исправления выполнены повторные тесты и проверка метрик.

## 7. Документация и авторство

- [ ] Добавлена актуальная архитектурная схема.
- [ ] Заполнена таблица прослеживаемости артефактов.
- [ ] Для командной работы описан индивидуальный вклад.
- [ ] Заполнена декларация использования генеративного ИИ.
- [ ] Студент готов выполнить небольшое изменение без подсказки готового решения.

## Подтверждение

Студент подтверждает, что защищаемая версия воспроизводима, не содержит опубликованных секретов и соответствует представленным доказательствам.
