# Дополнительные материалы

Каталог предназначен для материалов, которые не относятся к нормативным документам, КИМ или обязательным образовательным ресурсам: протоколов согласования, презентаций, вспомогательных схем и истории изменений.

Перед публикацией каждого файла необходимо проверить авторские права, отсутствие персональных данных и актуальность ссылок. Обязательные материалы курса должны размещаться в профильных каталогах, а не только здесь.
