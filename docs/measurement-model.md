## Правила интерпретации уровней

- **Б** — распознаёт понятия и выполняет действие по инструкции с объяснением основных рисков;
- **С** — самостоятельно выбирает и применяет инструменты, связывает артефакты и обосновывает решение;
- продвинутый уровень в данной дисциплине не заявлен и формируется на последующих проектных этапах.

Один элемент контроля может измерять несколько индикаторов. Уровень приведён отдельно для каждого индикатора, поэтому записи вида «С/Б» без расшифровки не используются.
