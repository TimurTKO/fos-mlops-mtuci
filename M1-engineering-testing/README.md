## Наблюдаемые результаты

1. Проект воспроизводимо устанавливается и запускается.
2. Код обучения и инференса разделён.
3. Контракт данных формализован.
4. Автоматические тесты выявляют реальные нарушения.
5. CI автоматически применяет quality gate.
6. Секреты не хранятся в репозитории.
