# Рубежная защита модуля 3

## Представляемый результат

Контейнеризированный ML-сервис, две идентифицируемые версии образа, автоматизированная проверка кандидата и воспроизводимый сценарий обновления/отката.

## Формат

- продолжительность — до 12 минут на проект;
- демонстрация выполняется из Git-репозитория;
- обязательны запуск Compose, smoke-тест и индивидуальные ответы;
- преподаватель вправе запросить небольшое изменение конфигурации;
- при командном выполнении каждый участник объясняет собственный вклад.

## Максимум — 6 баллов

| Критерий | 0 баллов | 0.5 балла | 1 балл |
|---|---|---|---|
| Воспроизводимая сборка и запуск | Образ или сервис не запускается | Запуск требует недокументированных действий | Сборка и запуск выполняются по README |
| API и готовность | Ключевые endpoint не работают | Работают частично либо healthcheck формален | `/health`, `/ready`, `/predict` и healthcheck корректны |
| Архитектура и контейнеризация | Решения не объяснены | Объяснение неполное | Стек, Dockerfile, сеть, модель и конфигурации обоснованы |
| Smoke-тест и критерии допуска | Автоматической проверки нет | Проверка неполна | Кандидат проверяется автоматически и блокируется при ошибке |
| Обновление и откат | Откат не продемонстрирован | Откат ручной или не подтверждён | Неуспешный выпуск выявлен, стабильная версия восстановлена и проверена |
| Безопасность, документация и понимание | Есть секреты либо студент не понимает проект | Есть некритичные пробелы | Секреты исключены, журнал и README полны, решения объяснены |

## Условия допуска к защите

- ЛР №6 и №7 представлены в репозитории;
- `docker compose config` выполняется без ошибки;
- локальные секреты не зафиксированы в Git;
- имеется как минимум один успешный smoke-тест;
- версии сервиса доступны через API;
- сценарий отката описан командами, а не только текстом.
